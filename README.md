# Learning Rust 🦀

Tracking my journey learning Rust from zero, working through Rustlings exercises
alongside The Rust Programming Language ("The Book"). Long-term goal: comfortable
enough with Rust to use it in robotics/embedded projects.

## Setup

- macOS (Apple Silicon / ARM native)
- Installed via `rustup`
- Exercises run via the `rustlings` CLI in watch mode — auto-checks on save
